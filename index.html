What is this?

There are two money jars. Jar 1 (Income) is planted in three big, boring investments and is meant to pay about Rs 1,000 every month. Jar 2 (Growth) is a small robot that trades Indian stocks to grow the pot, and hands extra money to Jar 1.

Right now both jars run on paper money (pretend rupees) so the robot can prove itself for two weeks before any real rupee moves. This page says what each jar is doing and what, if anything, you should do. Usually the answer is: nothing.

What should I do right now?

How the machine decides (and why)

  1. It only buys a pattern that already made money in a 5-year test.Every possible buy gets a score. Below the pass mark, it does nothing.
    Why: no gut feelings, no guessing. The same rulebook decides every single day, so results can be measured honestly.
  2. It waits for a cheaper price before buying.It leaves an order to buy only if the price dips to a set level. If the dip never comes, nothing is bought.
    Why: chasing a price up is how most beginners lose money.
  3. Every buy comes with the sell written first.The moment a buy happens, two exits are set: a stop (sell if it drops, keeping the loss small) and a target (sell if it rises, banking the profit).
    Why: a trade without an exit plan is a hope, not a plan.
  4. One trade can never lose more than 3% of the jar.On a Rs 50,000 jar that is Rs 1,500.
    Why: it would take roughly 33 losses in a row to empty the jar. The 5-year test never came close to that.
  5. It takes profit off the table early.Once a trade is comfortably ahead, part of the gain is banked instead of waiting for the full target.
    Why: in the 5-year test, banking early grew more money than holding out for the big win.
  6. It trades Indian stocks only.
    Why: tested with real costs, the US, crypto and forex legs did not pay for their own fees and taxes at this jar size. They can come back when the jar is much bigger.

The honest fine print

  • The test window had no crash. The 5-year test (Nov 2021 to Nov 2026) does not contain a 2008-style crash, so the real worst dip can be deeper than the tested numbers.
  • Rs 437/month per Rs 50,000 is a test average, not a promise. Some months will pay Rs 0. The plan needs years, not weeks.
  • Everything is paper money until about Nov 23, 2026. Two weeks of live paper trading must pass before real rupees are considered.
  • The robot never touches a real broker. It prepares tickets; you place any real order yourself in Zerodha.
  • 1 paper unit = Rs 500. Jar sizes are shown in rupees on that basis; share prices are real NSE rupee prices.
